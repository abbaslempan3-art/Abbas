ระบบ POS รองรับการบันทึกวิธีชำระและแยกช่องทางขาย แต่การรับชำระเงินอัตโนมัติและการรับออเดอร์จาก API ต้องได้รับสิทธิ์เชื่อมต่อจากผู้ให้บริการก่อน

💳 QR / PromptPay / บัตร

🛵 LINE MAN

🛵 ShopeeFood / Robinhood

บันทึกออเดอร์ด้วยมือ

เลือกช่องทางในหน้าขายได้ · รอการอนุมัติการเชื่อมต่อ

ห้ามนำรหัส API ลับหรือข้อมูลบัตรลูกค้ามาใส่ในหน้าเว็บโดยตรง ต้องใช้เซิร์ฟเวอร์ที่ปลอดภัยและ webhook ที่ตรวจสอบลายเซ็นก่อนเปิดรับชำระเงินจริง

รุ่นทดสอบ: บันทึกลงฐานข้อมูลจริง โปรดใช้บิลทดสอบก่อนเปิดใช้งานหน้าร้าน และยังไม่เชื่อมระบบรับชำระเงินหรือเดลิเวอรี่โดยตรง
