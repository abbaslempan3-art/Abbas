# Abbas AI Command Center V1

เว็บ Dashboard ภาษาไทยสำหรับบริหารธุรกิจและโครงการ AI ด้วย React, Vite และ TypeScript รองรับคอมพิวเตอร์และมือถือ ไม่มี backend และไม่เรียก API แบบเสียเงิน

## เริ่มใช้งาน

ต้องมี Node.js 22 ขึ้นไป และ npm

```sh
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดงในเครื่องของคุณ โฮสต์ dev server เปิดที่ `0.0.0.0` จึงควรใช้เฉพาะเครือข่ายพัฒนาที่เชื่อถือได้

```sh
npm run build
npm run preview
```

Build ตรวจ TypeScript ก่อนสร้างไฟล์ production ใน `dist/` สามารถนำไปโฮสต์แบบ static ได้

## ความสามารถ

- **ภาพรวม:** จำนวนโครงการ งานค้าง งานเสร็จ และงานเร่งด่วน พร้อมงานที่ควรโฟกัส
- **โครงการ:** เพิ่ม แก้ไข ค้นหา ลบ และปรับสถานะ ความคืบหน้าคำนวณจากงานที่เสร็จในโครงการ
- **งาน:** เพิ่ม แก้ไข ค้นหา ลบ ผูกกับโครงการ กำหนดวันครบกำหนด ความสำคัญ และสถานะ กดช่องหน้าชื่องานเพื่อสลับเสร็จ/รอดำเนินการ
- **CRM:** เพิ่ม แก้ไข ค้นหา ลบ ชื่อลูกค้า ธุรกิจ และสถานะการขาย
- **AI Tools:** ข้อมูลและลิงก์ ChatGPT, Codex, Grok, Metricool ทุกตัวระบุว่ายังไม่ได้ตรวจสอบการเชื่อมต่อ ไม่มี API integration
- **รายงาน:** สัดส่วนงานสำเร็จ จำนวนงาน/โครงการตามสถานะ และความคืบหน้ารายโครงการ

งานเร่งด่วน = งานที่ยังไม่เสร็จและมีความสำคัญสูง **หรือ** เลยวันครบกำหนด โดยนับหนึ่งครั้งต่อรายการ ใช้วันที่ท้องถิ่นของเบราว์เซอร์ งานที่ไม่มีวันครบกำหนดไม่ถือว่าเลยกำหนด สถานะโครงการปรับแยกจากสถานะงาน โครงการไม่มีงานแสดงความคืบหน้า 0% เมื่อลบโครงการจะเก็บงานไว้และยกเลิกการผูกโครงการ

## ข้อมูลทดลองและความเป็นส่วนตัว

เปิดครั้งแรกจะแสดงข้อมูลสมมติ บันทึกเมื่อเพิ่ม แก้ไข ลบ หรือเปลี่ยนสถานะใน Local Storage key `abbas-command-center-v1` การ reload จะอ่านข้อมูลที่บันทึกไว้ หากอ่านข้อมูลเดิมไม่ได้จะแจ้งเตือนและแสดงข้อมูลทดลอง การบันทึกรายการถัดไปจะแทนที่ข้อมูลที่อ่านไม่ได้ หากพื้นที่เต็มหรือสิทธิ์ถูกปิดจะเตือนและไม่อัปเดตข้อมูลในแอป

ข้อมูลอยู่เฉพาะ browser และ origin นี้ เปลี่ยน browser/port หรือเคลียร์ข้อมูลเว็บไซต์จะไม่เห็นข้อมูลเดิม ไม่เข้ารหัส ไม่มีบัญชีผู้ใช้ การสำรองข้อมูล การซิงก์ หรือการทำงานหลายคน/หลายแท็บพร้อมกัน จึงเหมาะกับข้อมูลทดลองเท่านั้น **ห้ามกรอกข้อมูลส่วนตัวจริง ข้อมูลลับ หรือ API keys** ไม่มีการฝัง keys หรือข้อมูลส่วนบุคคลจริงในโค้ด ไม่มีการโหลดฟอนต์หรือเรียก API ภายนอกโดยอัตโนมัติ ลิงก์ AI เปิดเว็บไซต์ภายนอกซึ่งอาจมีบริการเสียเงินของผู้ให้บริการเอง

## ทดสอบ

```sh
npm ci
npx playwright install chromium
npm test
npm run build
```

Linux บางเครื่องต้องติดตั้ง system dependencies ของ browser ด้วย `npx playwright install --with-deps chromium` หากมี Chromium อยู่แล้ว ใช้:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

Playwright จะเริ่ม Vite ให้อัตโนมัติ ชุดทดสอบใช้ browser context แยกกัน ครอบคลุม CRUD โครงการ/งาน/ลูกค้า การอ่านข้อมูลหลัง reload รายงาน การลบโครงการโดยคงงานไว้ เมนูมือถือ การระบุสถานะ AI และข้อผิดพลาด Local Storage

## โครงสร้าง

- `src/App.tsx` — หน้าหลัก ฟอร์ม รายงาน และ persistence
- `src/style.css` — ธีมและ responsive layouts
- `src/main.tsx`, `index.html` — จุดเริ่มต้น React และ HTML ภาษาไทย
- `vite.config.ts`, `tsconfig.json` — build configuration
- `tests/app.spec.ts`, `playwright.config.ts` — functional browser tests

V1 ยังไม่มีการเชื่อมต่อ AI จริง การแจ้งเตือนอัตโนมัติ export/import ฐานข้อมูล และระบบสิทธิ์ ควรเพิ่มระบบเหล่านี้ก่อนใช้งานธุรกิจจริง
