# Abbas AI Command Center V1 · Entrepreneur Workspace

ศูนย์บัญชาการ AI ภาษาไทยสำหรับผู้ประกอบการ ด้วย **React + Vite + TypeScript** รองรับมือถือและคอมพิวเตอร์ ต่อจาก V1 เดิมโดยเก็บความสามารถโครงการ งาน CRM และรายงานไว้ ไม่มีการสมัครบริการเสียเงินหรือเรียก AI API

## ติดตั้งและใช้งาน

ต้องมี Node.js 22+ และ npm ใช้ checkout ปัจจุบัน ไม่ต้องสร้าง worktree ใหม่

```sh
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดงในเครื่อง โฮสต์ dev server ใช้ `0.0.0.0` สำหรับเครือข่ายพัฒนาที่เชื่อถือได้

```sh
npm run build
npm run preview
```

Build ตรวจ TypeScript ก่อนสร้างไฟล์ production ใน `dist/` สามารถโฮสต์แบบ static ได้ Backend scaffold เป็นตัวเลือกสำหรับพัฒนาการเชื่อมต่อในอนาคต ไม่จำเป็นต่อ Frontend:

```sh
npm run backend
npm run test:backend
```

Backend เปิดเฉพาะ loopback port 8787 ดู [backend/README.md](backend/README.md) สำหรับ API contract และขอบเขตความปลอดภัย ไม่มี OAuth, API execution หรือ token storage ที่ใช้งานจริง

### รองรับบริบทธุรกิจ 5 แบบ

AI Marketing Studio, AI Kids Content Studio, ซื้อขายสินค้าและมอเตอร์ไซค์มือสอง, บริหารร้านอาหาร และเลขานุการส่วนตัว/ติดตามโครงการ เลือกธุรกิจได้ในโครงการ รายการเงิน แผนคอนเทนต์ และ Workflow รวมถึงใช้กรองคำแนะนำเครื่องมือ ตัวอย่างทั้งหมดเป็นข้อมูลสมมติ ไม่ใช่ข้อมูลลูกค้าหรือการเงินจริง

- **AI Assistants & Research (9):** ChatGPT, Gemini, Claude, Grok, Perplexity, DeepSeek, Microsoft Copilot, NotebookLM, Le Chat

ทะเบียนอยู่ใน `src/features/catalog.ts` เพิ่มรายการมาตรฐานด้วย metadata และ ID คงที่ (อย่าเปลี่ยน ID เมื่อสลับลำดับหรือเปลี่ยนชื่อ) หรือเพิ่มเครื่องมือส่วนตัวจากหน้า Directory ชื่อใหม่ต้องไม่ซ้ำ ลิงก์ต้องเป็น HTTPS ไม่มี user/password, query string หรือ fragment เพื่อไม่รับ URL ที่แนบ tokens ปุ่มเครื่องมือมาตรฐานเปิดเว็บไซต์ทางการ ส่วนรายการที่เพิ่มเองระบุว่าเป็นเว็บไซต์ที่ผู้ใช้กำหนด ไม่รับรองเจ้าของเว็บไซต์

รายชื่อรวมทั้งเครื่องมือ AI และแพลตฟอร์มธุรกิจที่มี AI/automation ตรวจชื่อและรูปแบบ URL แล้ว แต่การตรวจเว็บไซต์จาก cloud ครั้งนี้เข้าถึง GitHub Copilot ได้ 1 รายการ อีก 43 รายการถูก proxy ปฏิเสธ (403) จึงยังยืนยันการเข้าถึงปลายทางทั้งหมดไม่ได้ ดูหลักฐานรายรายการใน [docs/TOOL_URL_REVIEW.md](docs/TOOL_URL_REVIEW.md) การเปิดเว็บไซต์ได้ไม่ใช่การเชื่อม API หรือยืนยันสิทธิ์ใช้งาน

## วิธีคำนวณ

- **งานเร่งด่วน:** งานที่ยังไม่เสร็จและมีความสำคัญสูง หรือเลยวันครบกำหนด นับรายการละหนึ่งครั้ง ใช้วันท้องถิ่นของเบราว์เซอร์ ไม่กำหนดวันไม่ถือว่าเลยกำหนด
- **ความคืบหน้าโครงการ:** งานเสร็จ / งานทั้งหมดในโครงการ โครงการไม่มีงาน = 0% สถานะโครงการปรับแยกจากงาน ลบโครงการจะเก็บงานไว้และยกเลิกการผูกโครงการ
- **การเงิน:** รวมรายรับ/รายจ่ายตามเดือนและธุรกิจ คงเหลือ = รายรับ − รายจ่าย ไม่ใช่งบกำไรขาดทุนทางบัญชีหรือรายงานภาษี
- **งบ AI:** รวมงบรายเดือนที่ระบุเอง ไม่ทราบราคาเมื่อยังไม่ระบุ (ไม่ตีความว่าเครื่องมือฟรี) ยอดรวมยังไม่รวมรายการที่ไม่ระบุ งบใช้ค่าเดียวปัจจุบัน ไม่ใช่ประวัติราคา ไม่กรองตามเดือน/ธุรกิจ และ **ไม่บวกเข้าในรายจ่ายอัตโนมัติ** เพื่อป้องกันการนับซ้ำ
- **Sales Pipeline:** จำนวนลูกค้าตามขั้น ไม่คาดเดามูลค่าดีลหรือแปลงเป็นรายได้
- **Recommendation:** ตัวกรองหลายตัวใช้เงื่อนไขร่วมกัน จึงอาจไม่พบผลลัพธ์ ใช้ปุ่มล้างตัวกรองเพื่อเริ่มใหม่

## ข้อมูลทดลอง ความเป็นส่วนตัว และการเชื่อมต่อ

- เก็บโครงการ งาน และ CRM เดิมใน `abbas-command-center-v1` เพิ่ม field ธุรกิจแบบ optional โดยข้อมูลเก่ายังอ่านได้
- เก็บรายการโปรด เครื่องมือส่วนตัว งบ AI รายการเงิน คอนเทนต์ และ Workflow ใน `abbas-business-v1` (schema version 1) ไม่ลบหรือเขียนทับข้อมูลเดิมเมื่อเปิดแอป
- เริ่มจากข้อมูลสมมติหากยังไม่เคยบันทึก บันทึกเมื่อแก้ไขข้อมูล หากอ่านข้อมูลเสียหายไม่ได้จะแจ้งเตือนและใช้ตัวอย่าง การบันทึกครั้งถัดไปจะแทนที่ข้อมูลเสียหายของส่วนนั้น หากเขียนไม่ได้จะแจ้งเตือนโดยไม่อัปเดตข้อมูลในหน่วยความจำ
- ข้อมูลอยู่เฉพาะ browser/origin นี้ ไม่มีการเข้ารหัส บัญชีผู้ใช้ สิทธิ์ สำรองข้อมูล sync หรือรองรับหลายแท็บ/หลายคนแก้ไขพร้อมกัน การล้างข้อมูลเว็บไซต์อาจทำให้สูญหาย
- **ใช้ข้อมูลตัวอย่างเท่านั้น ห้ามกรอกข้อมูลลูกค้าจริง ข้อมูลเด็ก ข้อมูลการเงินจริง API keys, passwords หรือ tokens ในแอป/Local Storage** ไม่มีการฝังข้อมูลลับไว้ใน frontend
- ไม่มีการเรียกเว็บไซต์เครื่องมือ โหลดฟอนต์ภายนอก หรือส่งข้อมูลไป AI อัตโนมัติ ลิงก์เปิดแท็บใหม่เฉพาะเมื่อผู้ใช้กด เว็บไซต์ภายนอกมีข้อกำหนดและอาจมีค่าใช้จ่ายของตนเอง
- Workflow จำลองแสดงแผนข้อความตามขั้นที่กำหนด ไม่มี AI output, background jobs, webhooks หรือการเชื่อมต่อระหว่างเครื่องมือจริง
- Backend scaffold ตอบ 501 สำหรับ OAuth/execution ทุก endpoint จนกว่าจะพัฒนาระบบจริง เก็บ secrets ฝั่ง server เท่านั้นในอนาคต และแสดง connected ได้หลัง server ตรวจสิทธิ์สำเร็จเท่านั้น

## ทดสอบ

```sh
npm ci
npx playwright install chromium
npm test
npm run test:backend
npm run build
```

Linux บางเครื่องต้องใช้ `npx playwright install --with-deps chromium` หากมี Chromium อยู่แล้ว:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

Playwright เริ่ม Vite ให้เอง ทดสอบเดิม 3 ชุดยังคงอยู่พร้อมเพิ่มอีก 6 ชุด ครอบคลุม CRUD/persistence/report, รายชื่อและ URL 44 เครื่องมือ, หมวด/ค้นหา/คำแนะนำ, favorites/costs, เครื่องมือส่วนตัวและ URL ที่ไม่ปลอดภัย, การเงิน/Pipeline, คอนเทนต์/Workflow จำลอง, ไม่ส่ง request ออกภายนอก, มือถือ และ storage errors รวม **9 ชุดผ่าน** ส่วน backend มี **1 ชุดผ่าน** ตรวจ health/status/501/404 ผล build ผ่าน TypeScript และ Vite ดู [docs/PULL_REQUEST_ENTREPRENEUR.md](docs/PULL_REQUEST_ENTREPRENEUR.md) สำหรับขอบเขตตรวจทาน

## โครงสร้าง

- `src/App.tsx` — navigation, โครงการ/งาน/CRM เดิม, Pipeline และรายงาน
- `src/features/catalog.ts` — metadata เครื่องมือ 44 รายการ หมวด งาน และธุรกิจ
- `src/features/Directory.tsx` — Directory คำแนะนำ รายการโปรด เครื่องมือส่วนตัว และงบ
- `src/features/Business.tsx` — Executive, การเงิน, Content Planner, Workflow และ Settings
- `src/features/useBusiness.ts` — schema, validation และ Local Storage ของส่วนธุรกิจ
- `src/style.css` — SaaS theme และ responsive layouts
- `backend/` — HTTP scaffold, tests และแผน OAuth/API ที่ยังไม่เปิดใช้งาน
- `tests/` — Playwright regression/functional tests

V1 ยังไม่มี AI integration จริง การแจ้งเตือน การโพสต์คอนเทนต์ การเชื่อมธนาคาร บัญชีเต็มรูปแบบ export/import หรือ production security ต้องพัฒนาและตรวจสอบส่วนเหล่านี้ก่อนใช้ข้อมูลธุรกิจจริง
